# Tài liệu dự án — Smart E-Mobility Hub

Thư mục này chứa bộ **Software Project Documentation** chuẩn hóa cho dự án **Smart E-Mobility Hub** (Bài tập lớn Công nghệ phần mềm — CO3001, HK261, Lớp L03, Nhóm 17).

## 1. Bộ tài liệu cốt lõi

| Tài liệu | Mô tả |
| --- | --- |
| [**SRS.md**](SRS.md) | **Software Requirements Specification** — Bối cảnh, tác nhân, 14 Use Cases (UC01–UC14), tác vụ nền 2.3, NFR và **Ma trận truy vết (RTM)** nối yêu cầu ↔ mã nguồn ↔ kiểm thử. |
| [**SDD.md**](SDD.md) | **Software Design Document** — Kiến trúc 4 tầng, liên kết sơ đồ UML (Deployment, Package, Class), lược đồ CSDL SQLite/Drizzle và đặc tả API REST. |
| [**STD.md**](STD.md) | **Software Test Document** — Chiến lược kiểm thử (Unit/Integration/Manual E2E), quy ước mã TC, bảng tổng hợp test case 14 UC và hướng dẫn chạy test tự động (Vitest + Coverage). |
| [**USER_MANUAL.md**](USER_MANUAL.md) | **User’s Manual** — Hướng dẫn cài đặt, khởi tạo dữ liệu, chạy local/LAN, tài khoản demo và hướng dẫn sử dụng cho **Student** & **Operator** (kèm ảnh màn hình thực tế). |
